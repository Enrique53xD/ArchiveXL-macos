# ArchiveXL macOS port status (Cyberpunk 2077 2.3.1, Epic, arm64)

Last updated: 2026-10-06.

## Works (verified in game)
- RED4ext macOS fork, inline hooks (re-signed executable), plugin loading.
- Stages 1 and 2: mounts `Bundle/` and `archive/pc/mod`, discovers and reads `.xl` files.
- Archive-only mods (meshes, textures, refits) load correctly.
- RTTI registration and script natives (`scripts/Facade.reds`), so TweakXL, a minimal Codeware, redscript, Virtual Atelier 1.6.3 and Atomiic Shop 3.12 run end to end (store, scrolling, cart, purchase).
- Factory index: not ported as an extension; the vanilla `base\gameplay\factories.csv` is overridden by an archive generated with `cp2077-macos-tools/rdar/patch_factories.py`.
- Dynamic appearance names of items (`base!variant+attr=value%hash`):
  - `FindAppearanceDetour` hooks `EntityTemplate::FindAppearance` (file VA 0x103d79e90). When the exact name is missing it retries with the part before `!` and remembers the variant.
  - `MeshFindGuard` hooks `CMesh::FindAppearance` (0x103b62134). It is null-safe and expands `*{variant}` to the remembered variant (then `default`, then `black`).
- Dynamic mesh paths (`*base\...\<outfit>_{gender}_{body}.mesh`) are not resolved by the plugin: `cp2077-macos-tools/rdar/make_dynpaths.py` generates an archive that serves the real mesh under the literal path hash. Outfits whose pieces need different body fits use `{legs}` in edited piece entities.
- Atomiic outfits (Urban Sprinter, Dia Bodysuit, Task Force Ines, Cheerleader, Night Dance, Pure Desire, Secret Desire) are visible on the player.

## Key facts
- Mac layout: DynArray = {entries, capacity, size}; ResourceDepot groups at +0x10 (0x38 per element).
- `Main(Load)` is called twice by the loader, so there is a guard. The depot pointer is captured in `Red::Mac::g_depot`.
- Item factory request state machine: tick 0x100d39bc4, state 3 handler 0x100d3a5ec calls `EntityTemplate::FindAppearance`. Garment mesh callback: 0x103bbe49c.
- RDAR entries: the engine counts segments physically adjacent to the first one as inlined buffers and asserts that this equals `ninl` (`serializationAsyncSourceImpl`). Cloned entries must keep raw segments, contiguous, with the same `ninl`. CR2W buffer table entries carry disk size and CRC32 of the raw segment.
- With the same resource in two mod archives, the first one in alphabetical order wins.

## Not working yet
- Per-entity dynamic variants: the variant is global (`s_lastVariant`), so equipping items of different colours at once mixes them.
- Gender is fixed to `w`; hair colour (`*{hair_color}`) and `{material}` texture paths are not expanded.
- Extensions that need unlocated functions: ResourceLink, ResourcePatch, Mesh, FactoryIndex, Localization, Journal, Animation, Transmog, Attachment, Customization, Garment, PuppetState, QuestPhase, WorldStreaming, InkSpawner.

## Diagnostics (`MacCompat.cpp`)
- Logs: `/tmp/axl_va.log`, `/tmp/axl_depot.log`, `/tmp/axl_crash.log` (signal, fault address and frame chain as file VAs; counters are dumped on crash).
- Flags polled every second: `/tmp/axl_trace_on|off`, `/tmp/axl_scan_now`, `/tmp/axl_counts_reset|dump`.
- Call counters: up to 3000 functions from `/tmp/axl_count_targets.txt` (`MacCounters.inc` is generated by `cp2077-macos-tools/rdar/gen_counters.py`).
- Path alias map: `/tmp/axl_alias.txt` (`<from hash> <to hash>` per line, read at startup).
